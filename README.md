# TheScaleMethod Learning Platform

A Next.js application for TheScaleMethod learning platform with Next.js, NextAuth.js, and MongoDB.

## Features

- Modern Next.js architecture
- User authentication with NextAuth.js
- MongoDB Atlas integration
- Responsive design
- Easy deployment to Vercel

## Environment Variables

This project requires the following environment variables:

```
NEXTAUTH_URL=https://thescalemodemethod-next.vercel.app
NEXTAUTH_SECRET=your-secret-key
MONGODB_URI=your-mongodb-connection-string
```

## Deployment

This project is configured for easy deployment to Vercel.

Follow the instructions in `DEPLOYMENT.md` for step-by-step setup.
